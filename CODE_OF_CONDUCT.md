# Contributor Code of Conduct

This project and everyone participating in it is governed by the Contributor Covenant Code of Conduct. By participating, you are expected to uphold this code. Please report unacceptable behavior to the maintainers listed in `MAINTAINERS.md`.

The short version:
- Be respectful and considerate.
- Be open to constructive feedback.
- If you experience or witness unacceptable behavior, report it to the maintainers.

For the full text of the Code of Conduct see: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
