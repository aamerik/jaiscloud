# Security

If you discover a security vulnerability, please do **not** open a public issue. Instead:

1. Use GitHub's Security Advisories feature if available for this repository.
2. Contact the maintainers listed in `MAINTAINERS.md` so we can coordinate a fix and disclosure.

We aim to respond within 72 hours. When reporting, include:
- Summary of the issue
- Steps to reproduce (minimal repro if possible)
- Impact and severity

We will acknowledge reports, coordinate fixes, and publish advisories where appropriate.
